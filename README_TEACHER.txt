AP Biology Evolution Game - Teacher Backup Instructions

Primary web version:
- Railway link: use the link provided by the student.

Backup web version:
- GitHub static backup link: https://raw.githack.com/UmerR0108/biology-evolution-game/web-backup/index.html
- GitHub Pages backup link, if Pages is enabled: https://umerr0108.github.io/biology-evolution-game/

Offline/local backup:
1. Download the project ZIP:
   https://github.com/UmerR0108/biology-evolution-game/archive/refs/heads/main.zip
2. Unzip it.
3. Open the unzipped folder.
4. On Windows, double-click run_game.bat.
   On Mac/Linux, open a terminal in the folder and run: ./run_game.sh

If the script says Python is missing:
1. Install Python 3.11 or newer from https://www.python.org/downloads/
2. Re-run the script.

Game controls:
- WASD / arrow keys: walk
- Hold Shift: sprint
- E / Enter: interact
- J: open/close Field Journal
- Tab: cycle areas
- 1 / H, 2 / P, 3 / F: jump to Home, Pond, or Forest
- ESC: close journal or quit

If browser hosting fails because of school Wi-Fi or browser restrictions, the local version is the intended fallback.
